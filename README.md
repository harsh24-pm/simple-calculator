Simple Calculator (CLI)

A basic Command-Line Interface (CLI) Calculator developed using Python. The program performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division based on user input.

Features:

Addition
Subtraction
Multiplication
Division
Simple and user-friendly CLI interface
Handles basic invalid input and division-by-zero cases

Technologies Used: Python 
🐍Purpose: This project demonstrates the use of Python fundamentals, user input, conditional statements, and arithmetic operators.
